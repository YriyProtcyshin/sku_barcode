## Про продукт

**SKU Barcode & Retail Tools** — це сучасний веб-додаток, створений **для оптимізації та прискорення роботи торговельних представників при перевірці стоку марок**.

Додаток дозволяє за лічені секунди знаходити потрібні марки, об'єднувати їх у списки та миттєво генерувати точні штрих-коди прямо на екрані смартфона. Готові переліки можна легко надсилати відповідальним особам. Також він містить набір інтелектуальних калькуляторів для щоденної роботи торгового представника.

> [!NOTE]
> Додаток є **Progressive Web App (PWA)** і встановлюється на будь-який смартфон одним кліком — без App Store і без Google Play.

## 🌟 Ключові переваги

### 🌍 Мультимовність (i18n)

Додаток підтримує кілька мов інтерфейсу (наразі реалізовано: Українська та Англійська).

| Функція | Опис |
| :--- | :--- |
| **Автоматичне визначення** | Система самостійно виявляє мову системи та адаптує інтерфейс |
| **Легкість перемикання** | Миттєве перемикання мов без перезавантаження сторінки |
| **Збереження вибору** | Вибрана мова автоматично зберігається в `localStorage` |

### ⚡ Продуктивність та Офлайн-доступ (PWA)

| Функція | Опис |
| :--- | :--- |
| **Швидкість** | Абсолютна відсутність затримок при роботі з додатком завдяки використанню сучасного React-стеку |
| **Автономність (PWA)** | Додаток працює **без підключення до інтернету**. Встановлюється одним кліком |
| **Оптимізація трафіку** | Всі операції, розрахунки та база товарів виконуються та кешуються локально |

### 💾 Локальне збереження даних

Не потрібно створювати акаунти чи залежати від сторонніх серверів:

> Вибрані товари, проміжні дані розрахунків та налаштування мови зберігаються безпосередньо у браузері користувача (`localStorage`).
> При повторному відкритті додатку всі попередні дані та налаштування автоматично відновлюються.

### 📈 Гнучка архітектура та масштабування

*   **➕ Нові мови за хвилини:** Додавання нової мови — лише один JSON-файл з перекладом, без змін у коді.
*   **🔄 Гнучка база товарів:**

    <img src="./sku_json_preview.png" align="right" width="210" style="margin-left: 20px; border-radius: 10px; box-shadow: 0 4px 16px rgba(0,0,0,0.18);" alt="Приклад структури sku.json">

    База SKU підтягується з окремого файлу `sku.json` в папці проекту.

    **Переваги такого рішення:**
    - **Миттєвий доступ:** Дані завантажуються разом з інтерфейсом, нульова затримка
    - **Надійність:** Немає залежності від зовнішніх баз даних
    - **Просте оновлення:** Актуалізація назв та штрих-кодів — це лише заміна одного файлу

*   **🧩 Модульна структура:** Додавання нових калькуляторів не впливає на існуючий функціонал.

## ⚙️ Інтелектуальна синхронізація

В основі — кастомний модуль **`useSkuData`**, що реалізує двоетапну стратегію роботи з даними:

| Етап | Дія | Результат |
| :---: | :--- | :--- |
| **1** | Перший запуск → завантаження `sku.json` | Дані кешуються в `localStorage` |
| **2** | Повторні запуски → зчитування з `localStorage` | **Миттєвий старт без очікування сервера** |
| **3** | Фоновий `HEAD`-запит → перевірка `ETag` | Оновлення лише при реальних змінах файлу |
| **4** | Відсутність мережі → локальний кеш | **Повна підтримка офлайн-режиму** |

## 🚀 Хостинг та CI/CD (Vercel + GitHub)

Додаток розміщено на платформі **Vercel** у зв'язці з **GitHub**:

| Перевага | Деталі |
| :--- | :--- |
| **Безкоштовний хостинг** | Hobby plan — 0 грн/місяць |
| **Висока витривалість** | До 100 ГБ трафіку/місяць — з великим запасом для всієї команди |
| **Автоматичний деплой** | Будь-який push до GitHub → миттєва публікація на Vercel |
| **PWA-економія** | Код і база марок кешовані на пристрої → перевищення лімітів технічно неможливе |
| **Глобальна CDN** | Миттєвий доступ незалежно від якості мобільного інтернету |
| **Безпека** | SSL + захист від DDoS включені за замовчуванням |

## 📊 Аналітика використання (Google Analytics)

> [!IMPORTANT]
> **Вибір команди:** Використання інструменту не є обов'язковим — ніхто не змушує ним користуватися. Майже **100% залученість торгових представників** є виключно ініціативою самих співробітників, що є найкращим підтвердженням якості та зручності додатка.

Згідно з реальними даними аналітики, додаток демонструє високий рівень затребуваності:

![Статистика Google Analytics](./analytics_screenshot_final.png)

| Показник | Значення | Висновок |
| :--- | :---: | :--- |
| **Штат команди** | 14 осіб | Базова кількість користувачів |
| **Унікальних пристроїв** | 39 | ~2-3 пристрої на кожного представника |
| **Середньоденна активність** | 10–11 | Майже 100% команди щодня |
| **Охоплення в робочі дні** | ~100% | Інструмент став частиною робочого процесу |

*   **Мультидевайсність:** При штаті у **14 торгових представників**, додаток активно використовується на **39 унікальних пристроях**. В середньому кожен співробітник працює з інструментом на 2-3 пристроях (смартфон, планшет, ПК).
*   **Універсальність:** Це підтверджує ефективність PWA-архітектури — один додаток замінює три різні версії (iOS, Android, Windows), забезпечуючи синхронізацію та ідентичний досвід на будь-якому пристрої.
*   **Висока активність:** Середній показник складає **10-11 активних користувачів щодня**, що при штаті у 14 осіб свідчить про стабільну щоденну залученість команди.
